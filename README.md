# VIRUS - Trick - Windows 🎮

A collection of fun, harmless, visual "hacker" tricks and scripts built natively for the Windows Command Prompt (CMD).

## 🚀 Features
* **File Reading Matrix Loop:** A classic scrolling visual waterfall effect that reads all your files and folders created or downloaded onto your systemto simulate a hacker computer setup.
* **Pure Windows Native:** No external installations or complex configurations required. Runs straight out of the box using built-in `.cmd` Batch commands.

## 🛠️ How to Run
1. Open the project folder on your computer.
2. Double-click on `rainbow_matrix.cmd`.
3. To stop the script at any time, press **Ctrl + C** or simply close the command window.

## ⚠️ Disclaimer
*These scripts are completely harmless visual pranks. They do not inject malicious code, alter system settings, or harm your hardware.*
